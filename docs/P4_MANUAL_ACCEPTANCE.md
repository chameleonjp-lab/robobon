| 確認 | 期待する状態 | 結果 | 観察・修正案 |
|---|---|---|---|
| 時間線から出来事を1件選ぶ | 目的の出来事の3秒前から再生できる | 未実施 | |
| 観測事実と不足を分ける | 「原因の確定ではない」または「証拠が足りない」と表示する | 未実施 | |
| 3つの実験案を見る | 再戦、規則順、条件変更の3案が出る | 未実施 | |
| 自動変更の確認 | 実験案を押しても規則・装備・保存内容が変わらない | 未実施 | |

## P4-22 初見確認と修正判定

P4-22は、任務の問いと次の操作が初見の人へ伝わるかを別の5人で確認します。4項目すべてが4/5以上のときだけ合格です。

| 項目 | 合格条件 | 人数 |
|---|---|---:|
| 意味のある入力 | 30秒以内 | 未記入 / 5 |
| 導入戦終了 | 60秒以内 | 未記入 / 5 |
| 問いの説明 | 自分の言葉で説明 | 未記入 / 5 |
| 次の操作の説明 | 自分の言葉で説明 | 未記入 / 5 |

未達なら、問いの文章、段階の順番、カードの情報量のうち一つだけを変えます。最大2回まで再確認し、2回後も5人中3人未満が問いと次の操作を説明できなければ、P5へ進まず範囲縮小または再設計を選びます。
