# R02 導入戦の数値・任務・検証

更新日：2026-09-08

R02では、戦闘計算版 `r01-1` を維持したまま、武器・敵・任務の内容版を `r02-1` として管理する。保存済みのR01作戦を、説明なしに別の計算へ変換しないためである。内容の正本は `src/missions.ts`、1刻みの計算は `src/simulation/battle-step.ts` である。

## 共通の境界

| 項目 | 採用値 |
|---|---:|
| 競技場 | 640 × 360 |
| 規則評価 | 6刻み（0.1秒）ごと |
| 自機パルス砲 | 1発消費、16ダメージ、熱10、待ち時間30刻み、射程250 |
| 敵パルス砲 | 1発消費、26ダメージ、熱10、待ち時間45刻み、射程190 |
| 自機の冷却装置 | 25冷却、待ち時間90刻み |

射程の境界は「距離が射程以下」を含む。射線、照準、弾、熱、待ち時間は、カードの条件とは別に武器側の最終確認を通る。矩形の障害物は射線を遮り、機体の中心が障害物へ入らないよう移動を止める。

## 任務1「接近を観測する」

自機を `(170, 180)`、敵機を `(400, 180)` に置く。敵は射程外では `探索する` で近づき、射程へ入ると発射する。自機の初期6枚は、冷却・敵へ向く・発射・探索・後退（敵が近い）・横回避（弾の警告）の順で、後退と横回避を探索の下へ置く。探索より上へ移すカードを1枚だけ変えると、同じ開始条件で改善を比較できる。

| 作戦 | 自機の結果 | 敵の結果 |
|---|---|---|
| 初期作戦（探索が先） | 破壊、与ダメージ80 | 勝利、残り耐久20 |
| 後退カードを探索より上へ | 勝利、残り耐久22 | 破壊 |
| 横回避カードを探索より上へ | 勝利、残り耐久22 | 破壊 |

この比較は `runBattle(createGameSession(..., 'dock-approach'))` を同じ固定刻みで実行したもの。数値だけを下げて全作戦を勝たせる調整ではなく、敵の接近、弾、移動、勝敗を共通更新から再現する。

## 任務2・3の差

- 「熱の窓を守る」は1発の発熱を50とし、2発目で熱100へ到達する。冷却装置の使用、過熱開始、冷却後の再開が記録される。
- 「空いた時間を読む」は中央の `signal-wall`（`x=300..340`, `y=126..234`）を置く。開始時の射線は遮られ、横移動や後退で射線が通る時間を作る課題になる。

3任務はそれぞれ配置、敵作戦、武器または地形が異なる。任務選択時に作戦カードを書き換えず、選んだ任務の設定だけを戦闘へ渡す。

## 自動検証

`src/r02-mission.test.ts` で次を固定した。

- 弱点作戦は敵の破壊勝利、後退・横回避の各1枚変更は自機勝利。
- 射程の内側・境界上・外側で、事実と発射最終確認が一致する。
- 障害物で射線が遮られ、機体が障害物を通り抜けない。
- 戦闘の再生用スナップショットにも障害物を残す。
- 共通更新から過熱開始・冷却・発射を再現する。

R02で未確認の項目は、iPhone Safariの実機、白黒・文字拡大、初見利用者5人の理解確認である。これらは自動テストの成功をもって完了扱いにしない。
