# P4-19 出来事の時間線と3秒前再生

## 目的

戦闘結果を「勝ち／負け」だけで終わらせず、プレイヤーが自分の規則と出来事の関係を短時間で見直せるようにする。分析画面では、計算結果を編集したり再実行したりせず、戦闘中に記録した描画用スナップショットだけを再生する。

## 実装範囲

- `src/replay.ts`に再生フレーム、時間線項目、3秒（180刻み）の窓選択を分離した。
- 戦闘中は初期状態を含む最大1,201フレーム（20秒分）をメモリに保持する。各フレームは機体・弾・競技場・勝敗・直近64件のイベントをコピーし、保存作戦やIndexedDBへ書き込まない。
- 分析画面の時間線は、表示文のある`CombatEvent`だけを直近80件まで並べる。弾の寿命切れなど、単独で意味を説明しない内部イベントは表示しない。
- 時間線の項目をタップすると、その刻みの3秒前から低画質・演出を減らしたCanvasを1倍速で再生する。戦闘開始から3秒に満たない出来事は「記録開始時点から」と明示する。
- フレームが保持範囲外、Canvasを取得できない、または再生対象がない場合はボタンを無効化し、「再生データなし」と表示する。再生データを推測して補完しない。
- `prefers-reduced-motion: reduce`が有効な場合は、同じ対象フレームを静止表示し、再生を省略した理由をステータスへ表示する。

## 視覚・操作仕様

時間線は分析カード内の順序付きリストとし、各項目を44 CSSピクセル以上のボタンにする。時刻、出来事の短い説明、再生可否を同じボタンで伝え、色だけで再生可能かどうかを示さない。再生Canvasは装飾であり、出来事の説明と再生状態は隣接するHTMLのライブ領域に置く。

再生時は、時間線で選んだ出来事を終端フレームとして、開始時刻・対象時刻・再生完了を文章で通知する。再生中に別の項目を選んだ場合は前の`requestAnimationFrame`をキャンセルし、前のCanvasへ書き続けない。分析から編集へ移る時も再生をキャンセルする。

次の手動確認は未実施である。

1. iPhone Safariで戦闘終了後に時間線の項目を選び、機体・弾・危険区域を追える。
2. 再生完了後に「規則を直して再戦」へ移り、再生の`requestAnimationFrame`が残らない。
3. 320 CSSピクセル、白黒表示、200%文字、VoiceOver、動きを減らす設定で時刻・説明・再生可否が読める。
4. 20秒の最大戦闘で時間線80件・スナップショット1,201件の上限を越えてメモリが単調増加しない。
