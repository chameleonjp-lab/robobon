# P3-18 停止・速度・途中終了・背後復帰・3画質

- 対象: ロボボン
- 実装日: 2026-08-16
- 状態: コード実装済み。iPhone実機・画像比較の受入は未実施
- 対応箇所: `src/vertical-slice.ts`、`src/rendering/battle-renderer.ts`、`src/styles.css`

## 実装した動き

- 停止ボタンはクロックを止め、未処理の経過時間を捨てる。再開時は現在の刻みから始め、二重の描画要求を作らない。
- 1倍速と2倍速を用意した。速度は描画回数を増やさず、`FixedStepClock`へ渡す経過時間だけを変える。1回の描画で進む刻みの上限は従来どおり8刻みである。
- 「記録して編集へ戻る」は描画要求、音、ページイベントの購読を片付けてから作戦編集へ戻る。画面を開き直しても購読が増えない。
- `visibilitychange`で背後へ移った時、`pagehide`、戻る・進むキャッシュからの`pageshow`で戦闘を停止する。表示へ戻っても自動再開せず、利用者が「再開」を押すまで時間を進めない。
- 背景化時は音を止め、音ボタンをオフへ戻す。戻った後に音を自動で鳴らさず、利用者の操作で再開する。
- 高・中・低画質を追加した。低画質ほど床跡・煙などの装飾を減らすが、機体、弾、危険区域、状態カード、規則、勝敗は変えない。画質は停止中だけ変更できる。
- `prefers-reduced-motion`を初期値へ反映し、「演出を減らす」を個別に切り替えられる。計算結果と重要状態は変えない。

## 自動検査

- `FixedStepClock`の停止・復帰テストで、停止中に刻みが進まず、復帰時に古い経過時間を追いつかせないことを検査している。
- `scaleBattleElapsed`で1／2倍速の倍率と、遅延フレームの上限を検査している。
- `battleQualitySettings`で高24件・中12件・低0件の床跡上限と、低画質の演出削減を固定している。
- TypeScript型検査、Vitest、Vite build、`/robobon/` build smoke checkを通す。

## 未実施の受入確認

次はコード検査だけで合格扱いにしない。

1. iPhone Safariで停止、再開、1／2倍速、途中終了を行い、刻み飛び・二重音・二重ループ・入力固着がないか確認する。
2. ホーム移動、30秒背景、画面ロック、着信相当、戻る・進むキャッシュ、回転中の操作で、復帰後に自動再開せず現在状態が残るか確認する。
3. 高・中・低画質と「演出を減らす」を同じseed・同じ刻みで撮影し、重要情報と勝敗が一致することを画像比較する。差分は自動承認しない。
4. 初見5人中4人以上が、停止後にどの操作で再開するか、低画質でも何が変わらないかを説明できるか記録する。
