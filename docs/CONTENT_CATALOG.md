# ロボボン 代表作戦カタログ

- 文書版: 0.1（P0-01作業中）
- 作成日: 2026-08-13
- 目的: 規則カードの表現力と、戦闘後に原因を読めるかを早期に検証する

4作戦は、勝ち方を覚えるためではなく、異なる失敗理由を表現できるかを確認するために用いる。最初はバランサー、パルス砲、冷却装置、1対1の組み合わせで試す。敵と競技場の数を増やして解決しない。

## 作戦A：距離を保つ

### 問い

近距離へ入られる前に後退し、射程内でだけ撃てるか。

### 初期カード（上から順）

1. 敵が近い → 後退する
2. 弾が来ている → 横へ避ける
3. 敵との距離が射程内、かつ弾が残っている → 敵へ向く
4. 敵との距離が射程内、かつ弾が残っている → パルス砲を撃つ
5. 敵を確認 → 停止する
6. それ以外 → 探索する

### 予想される失敗

後退が先に働き続ける、砲塔だけが敵を向かない、弾が来たときの回避が遅れる。

### 成功の証拠

近距離に入った時間、撃った距離、弾を避けた回数が分析画面に出る。距離条件を1枚変えたとき、撃つ機会または生存時間が変わる。

## 作戦B：熱をためない

### 問い

弾を撃てる状態でも、熱で発射不能にならないか。

### 初期カード

1. 熱が高い → 冷却する
2. 弾が来ている → 横へ避ける
3. 射線が通る、かつ弾が残っている → 敵へ向く
4. 射線が通る、かつ弾が残っている → パルス砲を撃つ
5. 敵を確認 → 停止する
6. それ以外 → 探索する

### 予想される失敗

冷却が遅い、熱が高い条件が発射より下にある、冷却中に弾を受ける。

### 成功の証拠

過熱回数、熱量70以上の滞在時間、発射不能の回数が比較できる。熱条件を上へ移した結果を本人が説明できる。

## 作戦C：壁際で射線を作る

### 問い

遮蔽物の近くで撃てない時間を減らし、射線が通る場所へ移れるか。

### 初期カード

1. 進行方向が危険 → 横へ避ける
2. 敵が近い → 後退する
3. 射線が通る、かつ弾が残っている → 敵へ向く
4. 射線が通る、かつ弾が残っている → パルス砲を撃つ
5. 敵を確認 → 探索する
6. それ以外 → 停止する

### 予想される失敗

壁から離れる条件が広すぎる、射線が通らないのに発射しようとする、探索方向が壁へ向く。

### 成功の証拠

遮蔽時間、射線が通った時間、発射を見送った回数が出る。壁の位置を変えても、同じ規則の意味を説明できる。

## 作戦D：危険区域を渡らない

### 問い

敵を見ながら、発動前の危険区域へ入らずに移動できるか。

### 初期カード

1. 進行方向が危険 → 横へ避ける
2. 弾が来ている → 後退する
3. 敵との距離が射程内、かつ弾が残っている → 敵へ向く
4. 敵との距離が射程内、かつ弾が残っている → パルス砲を撃つ
5. 敵を確認 → 停止する
6. それ以外 → 探索する

### 予想される失敗

危険区域が発動した後に回避する、弾回避と危険回避が競合する、停止カードが下位で働かない。

### 成功の証拠

危険区域へ入った回数、予告を見てから移動した時間、被弾と侵入の順番が時間線で追える。

## 代表作戦の共通検査

| 検査 | 合格条件 |
|---|---|
| 表現力 | 4作戦中3作戦以上を最大8枚で組める |
| 修正の違い | 5人全体で2種類以上の異なる修正案が出る |
| 結果の説明 | 初見5人中4人が変更と結果の関係を説明する |
| 証拠 | 各作戦に時間、規則、出来事の3種類の証拠がある |
| 一意解の回避 | 4作戦すべてで、少なくとも2通りの改善案が成立する |

条件が足りない場合は、カードを増やす前に「状態を覚える条件」または「行動の継続・中断」のどちらが必要かを切り分ける。自由なコード入力や広い配線盤面は追加しない。
