# P3-16 武器・命中・仮音・煙・床跡

- 対象: ロボボン
- 実装日: 2026-08-16
- 状態: コード実装済み。音なし・白黒・最大演出・初見5人の受入は未実施
- 対応箇所: `src/rendering/battle-renderer.ts`、`src/audio/battle-audio.ts`、`src/vertical-slice.ts`

## 実装した表現

戦闘計算が記録した出来事を、固定刻みの年齢だけで短く描く。時計の時刻、乱数、外部通信は使わないため、同じ`CombatState`なら同じ発射光、命中輪、煙、床跡になる。

- 発射: 発射元の相手方向へ、短い光の扇形を3刻みだけ表示する。
- 命中: 対象の中心から輪と5本の破片線を8刻み表示する。煙は最大9刻み、薄い灰色で描き、機体と弾道を完全には隠さない。
- 床跡: `HIT_CONFIRMED`の直近24件だけを楕円の焦げ跡として残す。保存数を増やし続けず、描画の負荷を固定する。
- 過熱: 熱量バーに加えて、70以上または過熱中の機体へ破線の弧と`!`記号を表示する。色だけで状態を伝えない。
- 仮音: 初期状態は音なし。利用者が「音を開始」をタップした後だけ、発射・命中・過熱を短い波形で鳴らす。音を止めても画面の情報は変わらない。

## 描画と計算の境界

`src/simulation/combat.ts`の勝敗、命中、弾数、熱、出来事の順序は変更していない。描画側は`CombatEvent`の種類と刻みを読み、発射元・対象の現在座標へ効果を重ねるだけにする。戦闘状態が持つ出来事は上限4,096件、床跡は直近24件、効果の走査は直近32件に制限する。

音は`AudioContext`が使えない場合に失敗しても戦闘を止めない。音声コンテキストは利用者のタップ後に作成し、画面を離れると破棄する。外部音源やネットワークは使わない。
