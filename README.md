# ロボボン

「命令を組む → 自動戦闘を観察する → 原因を読み、組み直す」を中心にした、縦画面向けの独自2Dブラウザゲームです。

プレイヤーはロボットを直接操作しません。「敵が近いなら撃つ」「弾が来たら横へ避ける」といった行動規則を縦に並べ、15〜45秒の自動戦闘を観察します。戦闘後は失敗した場面と理由を確認し、規則や装備を直して再戦します。
