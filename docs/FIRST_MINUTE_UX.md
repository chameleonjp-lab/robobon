# 最初の1分間の導線と受入

この文書は、公開版の画面をゲームクリエイターの視点で確認し、最初の1分に必要な情報を画面の順序へ落とし込んだ記録です。外部作品の画面やルールは参照せず、`docs/GAME_RULES.md`、`docs/VERTICAL_SLICE.md`、`src/simulation/`、既存の変更履歴を正本にします。

## 公開版の確認結果

確認した公開ページは、P0〜P4の試作画面、縦切り編集、描画スパイク、素材ギャラリーを一つの長いページへ連結していました。名前入力なしで編集面へ入り、開始ボタンはページ下部にあり、戦闘中も編集・スパイク・ギャラリーが下へ続いていました。結果は現在位置に追加されるため、最上部から「何が起きたか」を読み始められませんでした。

この状態では、利用者が最初に答えるべき「何を組むか」「何を見ればよいか」「何を直すか」が画面の順序に結び付きません。今回の修正では、同じゲームルールをホーム、作戦、戦闘、結果の4状態へ分け、各状態に次の一手を一つだけ置きました。

## 現在のゲームルールに基づく要約

- プレイヤーは戦闘中のロボットを直接操作しない。
- 条件と行動のカードを上から並べ、最初に成立したカードの行動を採用する。
- 条件は敵の確認、距離、飛来弾、弾数、熱、境界、射線など、既存の`RuleFacts`を使う。
- 行動は敵へ向く、パルス砲、後退、横へ避ける、冷却、探索、停止の既存一覧を使う。
- パルス砲は弾数・射程・待ち時間・射線を確認し、冷却は熱を下げる。戦闘は固定刻みで進み、初期任務は20秒で終了する。
- 終了は相手の破壊、時間切れ、同時撃破、またはプレイヤーのリタイア。通常の時間切れの勝敗は残り耐久率、熱、与ダメージの順で既存実装が判定する。
- 結果は勝敗だけでなく、残り耐久、熱、弾、与ダメージ、観測できた出来事を確認して再戦する。

## 最初の1分の情報設計

| 時間 | 画面 | 利用者が理解すること | 画面に残す情報 |
|---|---|---|---|
| 0〜10秒 | ホーム | ロボボンは作戦を組み、自動戦闘を見て、結果から直すゲーム | ゲーム名、目的、1戦の終了条件、3手順 |
| 10〜20秒 | ホーム | 自分の名前と任務を選ぶと開始できる | 名前欄、開始不可の理由、任務の問い、選択中の枠 |
| 20〜35秒 | 作戦 | カードは上から確認し、最初に成立した行動が実行される | 任務の問い、「今すること」、優先番号、条件→行動、開始前検査 |
| 35〜55秒 | 戦闘 | ロボットは自動で動き、今光っている行動と数値を見ればよい | 「今すること」、固定Canvas、実行中カード、双方の耐久・熱・弾、直近の出来事 |
| 55秒以降 | 結果 | 事実を一つ選び、1枚だけ直して再戦する | 最上部の結果、時間、耐久、与ダメージ、共有、再戦、実験場へのリンク |

## 状態ごとの責務

### ホーム

最初にゲーム名、目的、終了条件を短く説明します。名前が空欄または空白だけの場合、開始ボタンを無効にします。任務は既存の3任務から選び、枠と「選択中」の文字の両方で状態を示します。共有とカメレオンJPの実験場へのリンクをここに置きます。

### 作戦を組む

任務の問いと「今すること」を上部へ置き、カードには優先番号、条件、行動、要約を同じカード内で表示します。カードをタップすると選択カードだけに枠と文字が付きます。細かな継続時間、上下、削除はカード内に残し、ドラッグや長押しを要求しません。開始前検査の警告は表示しますが、既存仕様どおり注意だけでは開始を止めません。

### 自動戦闘を見る

戦闘は画面高に固定し、文書の上下スクロールを禁止します。Canvasは装飾レイヤー、HTMLの状態表示を情報の正本とします。「今すること」は現在の行動や直近イベントに更新し、実行中のカード、数値、短いイベント文を複数同時に更新します。速度と音は同じ画面に残し、表示設定・遊び方・リタイアは一時停止の中にまとめます。

### 結果

結果画面へ遷移した時点でページの先頭へ戻します。最初に結果と終了理由、4つの数値、次の一手を表示し、観測事実・証拠・時間線・再生は折りたたみへ収めます。同じ作戦で再戦、カードを直して再戦、ホームへ戻る、結果共有、カメレオンJPの実験場を結果画面から選べます。

## 受入チェック

自動検査だけで合格にせず、同一の本番ビルドをブラウザで次の順に確認します。

1. ホームで名前が空欄のまま開始できないこと、名前入力後に開始できることを確認する。
2. 任務選択の枠と「選択中」が変わり、作戦画面の上部に任務の問いと「今すること」が出ることを確認する。
3. 条件・行動を変更して「出撃する」を押し、戦闘が始まることを確認する。
4. iPhone縦幅（320×568を含む）とパソコン幅で、戦闘の`scrollHeight`がviewport高を超えず、停止・速度・音へ到達できることを確認する。
5. 一時停止から再開、遊び方、リタイア確認を順に選べることを確認する。
6. 通常戦闘を最後まで進めて勝敗または時間切れを表示し、数値・短い文章・Canvasの変化があることを確認する。
7. 結果が先頭から表示され、結果共有、実験場、同じ作戦で再戦、規則を直して再戦が選べることを確認する。
8. 結果の時間線を開き、保存された場面を再生してから再戦できることを確認する。
9. 長押し、二重タップ、ピンチなしで全操作を完了できることを確認する。

ブラウザ検査は、文字が小さくなりすぎる320 CSSピクセル幅、iPhone縦画面相当、パソコン幅の3種類以上で行います。実機Safari、VoiceOver、初見利用者の受入は別途未実施として扱い、CI成功だけで完了へ繰り上げません。
