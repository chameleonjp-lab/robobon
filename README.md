# ロボボン

## プレイヤーは何をする？

ロボットを直接操作するのではなく、「敵が近いときは後退する」といった条件と行動を並べて作戦を作ります。自動で進む戦闘を見て、うまく動かなかった理由を考え、カードの優先順などを調整して再挑戦する遊びです。

- 作戦を組む → 戦闘を観察する → 1枚を変える → 結果を比べる、という短い試行を繰り返します。
- 射撃だけでなく、敵へ向く、探索する、過熱時に冷却する、近い敵から退くといった行動を使います。
- 現在は開発中の試作版です。遊びの調整や演出の仕上げ、初見・実機での検証は、以下の開発状況と分けて確認してください。

## 作品と開発状況

条件と行動のカードで作戦を組み、ロボットの自動戦闘を観察し、1枚だけ直して再戦する2Dブラウザゲームです。主対象はiPhone 17 Proの縦画面です。

## 開発・検査

Node.js 24以降を使用します。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run check:build
npm run dev -- --host 127.0.0.1
```

PRのCIではテスト、型検査、配信物検査、レビュー用成果物の作成を行います。mainへ直接pushせず、Draft PRで確認します。Pagesはmainの更新時に配信されます。
