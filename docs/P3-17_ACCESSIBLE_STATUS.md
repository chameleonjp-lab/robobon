# P3-17 戦闘状態のHTML表示と読み上げ

- 対象: ロボボン
- 実装日: 2026-08-16
- 状態: コード実装済み。iPhone実機・VoiceOverの受入は未実施
- 対応箇所: `src/battle-status.ts`、`src/vertical-slice.ts`、`src/styles.css`

## 目的

戦闘の意味をCanvasの絵だけへ閉じ込めない。実行中の規則、味方と敵の稼働状態、耐久、熱、弾数、直近の出来事、停止・再開をHTMLでも読めるようにし、画面を拡大した場合やCanvasを見られない場合でも同じ判断へ到達できる状態を作る。

## 実装した表示

- Canvasは装飾レイヤーとして`aria-hidden="true"`にし、HTML状態パネルを情報の正本にした。
- 実行中規則は`aria-live="polite"`の短い文章で表示し、規則が変わった時だけ更新する。0.1秒ごとの評価を連続して読み上げない。
- 「自機（味方）」と「敵機」を`article`で分け、`dl`へ稼働状態、耐久、熱、弾数を置いた。過熱中・停止は数値だけでなく日本語で示す。
- 直近の出来事は最大4件の順序付きリストへ置く。発射、命中、過熱、行動不可、冷却、戦闘終了を短い文章へ変換し、弾の寿命切れは一覧を埋めない。
- 重要な出来事、音の切替、停止・再開は別の`role="status"`へ通知する。刻みごとの耐久更新はライブ領域にしない。
- 停止ボタンは`aria-pressed`と「戦闘を一時停止／再開」のラベルを状態に合わせて更新する。音ボタンも押下状態を持つ。
- 状態カードは320 CSSピクセル付近で1列へ切り替え、長い文章と数値を折り返す。Canvasを非表示にしても主操作と状態パネルは残る。
