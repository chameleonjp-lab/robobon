# P0-03 描画負荷試作

- 対象: ロボボン
- 状態: 試作画面を追加。実機測定と描画方式の決定は未完了
- 目的: 本番素材を量産する前に、Canvas 2Dで必要な同時描画量、視認性、端末負荷を確認する

## 試作の範囲

この画面は本編ではない。次の固定負荷を、決めた順序で毎フレーム描く。

- 機体2体（味方1、敵1）
- 弾64発
- 粒子250個
- 競技場の線、危険区域、影、砲塔、簡易HUD
- 透明部分を含む仮のスプライトを1枚のCanvasアトラスへまとめ、`drawImage`で取り出す

仮スプライトはコードで作る一時素材であり、完成素材や元作品の参照画像ではない。最終素材の形、材質、権利、アトラス寸法はP0-04で別に決める。

## 画質の比較

重要な情報（機体、弾、危険区域、HUD）は全画質で残す。減らす対象を装飾へ限定し、画質変更で勝敗や計算を変えない。

| 画質 | 残す表現 | 減らす表現 |
|---|---|---|
| 高 | 粒子250、弾道、影、危険境界、HUD | なし |
| 中 | 粒子160、弾道、危険境界、HUD | 機体の影 |
| 低 | 粒子64、危険境界、HUD | 弾道の残像、機体の影、装飾粒子 |

「演出を減らす」を選んだ場合は低画質へ切り替え、画面の揺れや点滅を追加しない。ページを背後へ移したときは`visibilitychange`で停止し、復帰時に経過時間をまとめて処理しない。

## 計測方法

画面の開始後、同じ画質・速度で5分間動かす。開始直後の揺れを除くため、最初の30秒を別に扱う。次の情報を記録する。

- 端末名、OS、Safari版、低電力モード、冷間起動か再訪か
- 画質（高・中・低）、速度（1倍・2倍）、画面サイズ、端末の倍率
- 描画時間の中央値（p50）、95パーセンタイル（p95）、99パーセンタイル（p99）
- 33.3ミリ秒を超えた割合、50ミリ秒を超えた割合、停止・再読込・発熱の有無

目標値は、1倍速・高画質・最大負荷でp95が16.7ミリ秒以下、p99が33.3ミリ秒以下、50ミリ秒超が0.1%以下とする。これは試作の合否目標であり、現在は自動検査の値を実機結果の代わりに扱わない。

## 判定と次の分岐

実機記録がそろうまで、Canvas 2Dを採用したとは決めない。

- 目標値を満たし、敵味方・向き・弾道・HUDが読める場合: Canvas 2Dを継続する
- 目標値を満たさない場合: 粒子、影、残像の順に減らして再測定する
- それでも満たさない場合: PixiJSなどWebGL系の候補を、同じ負荷・同じ結果・対応端末条件で比較する

P0-03の完了条件は、実機の計測記録、画質ごとの差分、採用または交換の理由、独立レビューを同じPRへ残すこととする。Pagesの一般公開は、名称・独自性・完成条件のゲートを通るまで行わない。
